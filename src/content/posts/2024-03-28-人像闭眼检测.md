旧版使用 Haar 眼睛检测框高度与人脸框高度的比值判断闭眼，这个规则没有可靠依据。检测框不是上下眼睑距离，检测不到眼睛也不能直接判为闭眼。本文改为说明眼部关键点方法，并把示例能力限定为**已取得关键点后的状态判定**。

## 1. 检测眼睛不等于识别开合

OpenCV 的 Haar 分类器适合演示人脸与眼部定位。它可能受姿态、眼镜、遮挡和光照影响，闭眼时也可能漏检。`minNeighbors` 等参数调整检测灵敏度，不能凭空提高模型的闭眼识别能力。

一个完整流程需要：人脸定位 → 眼部关键点 → 开合特征 → 质量检查 → 连续帧状态。多人场景还需分别跟踪每个人，不能混用不同人脸的历史状态。

## 2. 眼睛纵横比 EAR

按图中顺序给单眼六个点编号 `p1…p6`：两个眼角为 p1、p4，上眼睑为 p2、p3，下眼睑为 p5、p6。定义：

`EAR = (|p2-p6| + |p3-p5|) / (2*|p1-p4|)`

这里的距离为欧氏距离。眼睛闭合时竖向距离通常减小，EAR 下降。公式来自 [Soukupová 与 Čech 的眼眨动检测论文](https://vision.fe.uni-lj.si/cvww2016/proceedings/papers/05.pdf)。不同关键点模型的编号不同，必须先映射到图中顺序。

## 3. 可运行的关键点计算示例

安装 NumPy 后可直接运行下例。输入是假设的二维关键点，并非人脸模型推理结果；不包含摄像头采集、自动定位或身份跟踪。

```python
import numpy as np


def eye_aspect_ratio(points):
    p = np.asarray(points, dtype=np.float64)
    if p.shape != (6, 2) or not np.isfinite(p).all():
        raise ValueError("需要六个有限的二维眼部关键点")
    width = np.linalg.norm(p[0] - p[3])
    if width <= 1e-6:
        raise ValueError("眼角间距过小，关键点无效")
    return float((np.linalg.norm(p[1]-p[5]) +
                  np.linalg.norm(p[2]-p[4])) / (2.0*width))


class EyeState:
    def __init__(self, threshold=0.2, min_frames=3):
        if not np.isfinite(threshold) or threshold <= 0 or min_frames < 1:
            raise ValueError("阈值必须为正，连续帧数至少为一")
        self.threshold = threshold
        self.min_frames = min_frames
        self.low_frames = 0

    def update(self, points):
        if points is None:
            self.low_frames = 0
            return "Unknown"
        try:
            ear = eye_aspect_ratio(points)
        except ValueError:
            self.low_frames = 0
            return "Unknown"
        self.low_frames = self.low_frames + 1 if ear < self.threshold else 0
        if self.low_frames >= self.min_frames:
            return "Closed"
        return "Pending" if self.low_frames else "Open"


if __name__ == "__main__":
    opened = [(0, 0), (1, -1), (3, -1), (4, 0), (3, 1), (1, 1)]
    closed = [(0, 0), (1, -0.1), (3, -0.1), (4, 0), (3, 0.1), (1, 0.1)]
    state = EyeState()
    print("EAR:", eye_aspect_ratio(opened), eye_aspect_ratio(closed))
    print([state.update(p) for p in [opened, closed, closed, closed, None]])
    # EAR: 0.5 0.05；状态：Open、Pending、Pending、Closed、Unknown。
```

`0.2` 与三帧只是演示参数，不能作为跨人群通用阈值。实际接入时应根据已知开闭状态的样本标定；帧率波动明显时，用连续持续时间替代固定帧数。图像坐标归一化时，x、y 必须使用一致尺度，否则距离比值会受图像纵横比影响。

## 4. 验证与局限

验证集需包含正常睁眼、眨眼、长时间闭眼、转头、遮挡、眼镜、无脸和多人情况。分别记录漏检与误报，缺失或低置信度关键点输出 `Unknown`，不要把它归入 `Closed`。

本例不是完整实时识别系统。OpenCV 的定位入门可参考 [Haar 人脸与眼部检测说明](https://docs.opencv.org/4.x/d2/d99/tutorial_js_face_detection.html)；实际关键点模型的依赖、许可、编号和推理精度应在接入时单独说明。旧版缺少可复现输入和模型的“识别结果”截图已移除，当前图片为算法示意。
