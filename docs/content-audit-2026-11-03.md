## 验证方法与结果

- `npm run check`：无错误、无警告，三项提示涉及站点脚本与 Astro 注入变量，不属于文章内容。
- `npm run build`：21 个页面构建通过，原文章路由保留。
- `npm run check:content`：12 篇文章、23 张本地正文配图、58 个代码块；检查围栏、语法、JSON/YAML、文件存在性、已构建本站链接及 Fetch 的 HTTP 500／成功路径。
- `npm run test:post-examples`：直接执行文章中的 Python 字典、EAR 和清晰度函数；使用 OpenCV Core 编译原文 C++，验证二十种模式的 204020 组网格结果、独立数值样例、端点、恒等式与图层交集。C++ 开启 UndefinedBehaviorSanitizer。
- `npm run test:article`：既有性能文章的 625 组矩阵、517 组字节字符串及地址／未定义行为消毒器回归。
- `npx playwright test tests/articles.spec.ts --workers=2`：25 项通过、1 项有意跳过。覆盖 12 篇文章在手机与桌面尺寸下的图片解码、替代文本与溢出；WebGL 软件实现编译混合和两种全景 shader，执行 49 个通道样例及透明／不透明底图 Alpha 检查。相同 Shader 不在手机项目重复执行。

## 证据和边界

技术校订参照 W3C 混合与合成定义、Khronos API 定义、Qt QOpenGLWidget、Android ViewGroup／ViewPager2、OpenCV 梯度说明及 EAR 原论文；相应链接置于正文。自律星球以公开仓库 README 与原文截图为依据，不把 README 或截图视为完整发布验收。

本次不声称已在 Android 真机、Qt 桌面 OpenGL 上下文、各类相机关键点模型或上游 JPEG 解析器执行全量端到端测试。浏览器可编译的 ES shader 已实际编译，其他宿主片段明确标出上下文、依赖和集成范围。文章图解均为算法或结构说明，不冒充新测量截图。

本机 OpenCV 的全量链接受缺失 FFmpeg 库影响，回归只链接实际需要的 Core。AddressSanitizer 与本机 TBB 在进程退出时出现库析构崩溃，因此混合模式的 OpenCV 集成采用 UndefinedBehaviorSanitizer；既有独立 C++ 性能回归仍使用地址与未定义行为消毒器，未修改系统库。
