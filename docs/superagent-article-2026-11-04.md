## 原创内容

新增 `/2026/11/04/superagent工程拆解/`。用图片方向错误的工程场景串起任务身份、协调／执行分工、事件准入、订阅直通、上下文预算、异步交付、恢复代次、执行环境及人的注意力。

- 三张原创 SVG 正文图：职责拆分、上下文引用、恢复代次；另绘制一张原创 SVG 封面。
- 离散事件教学模型 `public/examples/superagent-runtime.mjs`：浏览器与 Node.js 共用，零第三方依赖。
- 事件路由场景：过滤闲聊和未获准的新工作、按 ID 去重、已订阅讨论补充直通、两项任务分别登记结果。
- 恢复场景：序列化／恢复 JSON 状态、注入无进展信号、增加执行代次、拒绝迟到结果与重复回调。单元回归还覆盖重试上限转人工。
- 上下文实验：调整 120～600 字符预算，先保留引用再填片段，可展开完整本地资料；预算不是 token，教学模型没有真实检索或模型调用。

代码不发送消息、不创建外部 PR、不执行后台命令。模拟进程恢复不是实际崩溃注入；代次只保护模型内状态，不保护已经发生的外部副作用。一条本地结果登记不等于端到端只投递一次。这些范围已写入正文。
