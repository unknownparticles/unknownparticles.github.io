# 性能文章扩展与交互验证

日期：2026-11-04。回应文章范围被过度收窄的问题，保留原路由，扩展为多方法教学文章。正文去除代码块后约 4970 个汉字，覆盖定位热点、滑动窗口、减少判断、内存访问、查表、预分配、量化、SIMD、多线程、GPU 取舍与编译器优化。

## 可运行内容

- `public/examples/cpp-optimization.cpp`：从文章函数片段与入口拼接的 C++17 套件；可独立编译。含窗口、行列遍历、亮度查表、容器预分配、量化、SIMD 和线程归并。
- `public/examples/cpp-matrix.cpp`：保留矩阵边界与最长无重复字节子串的独立校验，625 个矩阵与 517 个字符串。
- `npm run test:article` 直接提取正文，检查下载文件内容完全一致，以 ASan/UBSan 编译并执行两套用例。
- `npm run test:article -- --bench` 另以 `-O3 -pthread` 构建；主套件预热后交替顺序运行七轮，报告中位数与范围；原矩阵用例保持原来的单轮观察模式，正文明确区分。
- 实际执行平台：Apple M1、darwin/arm64、Apple clang 21.0.0。ARM NEON 路径已执行；x86 SSE2 分支与其他架构回退尚未在对应硬件执行。

套件验证空输入、无效窗口、正负数、矩形与退化尺寸、查表全部 256 个输入和 -255～255 偏移、SIMD 全部非负偏移及短数组尾部，并补充 257/1023/4099 长度；量化检查区间截断和 10001 个取样误差，线程检查零线程拒绝与 1/2/4 路归并。有限样本不等于对任意输入的形式证明，文章明确输入约束。
